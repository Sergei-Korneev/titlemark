# Titlemark

> *titlemark* — титульная метка: короткое название, которое в старопечатных
> книгах ставили в верху страницы, чтобы опознать книгу.

**Titlemark** — консольная утилита, которая читает документ, определяет его
**заголовок и автора** и переименовывает файл в понятное имя:

```
29623753.pdf                    ->  David Knickerbocker - Network Science with Python [2023].pdf
43b2956cd82bc62159778acf….pdf   ->  Артур Думчев - ПОМНИТЬ ВСЕ ПРАКТИЧЕСКОЕ РУКОВОДСТВО ПО РАЗВИТИЮ ПАМЯТИ [2013].pdf
345852.fb2                      ->  Штюрмер Ю. А. - Карманный справочник туриста.fb2
```

Работает **офлайн**, без LLM и внешних сервисов: только эвристики по
метаданным, текстовому слою и (для сканов) OCR.

## Форматы

| Формат | Метаданные | Текст | OCR |
|--------|-----------|-------|-----|
| PDF    | pdfinfo   | pdftotext (poppler) | pdftoppm + tesseract |
| EPUB   | package.opf (dc:title, dc:creator, dc:date) | – | – |
| FB2    | title-info (book-title, author, date) | – | – |
| MOBI   | PalmDB + EXTH (title, author, date) | – | – |
| DJVU   | аннотации ANTa (title, author) | djvutxt (djvulibre) | ddjvu + tesseract |
| DOCX   | docProps/core.xml | первые абзацы | – |

**Файлы без расширения** (имена-хэши в папках загрузок) распознаются по
сигнатуре: магические байты PDF/DjVu/MOBI, устройство контейнера EPUB/DOCX,
корневой тег `FictionBook` у FB2 — и при переименовании файл получает
правильное расширение. То же работает для файлов с неверным или неизвестным
расширением.

## Зависимости

* Python ≥ 3.10, только стандартная библиотека;
* для PDF: `poppler-utils` (`pdfinfo`, `pdftotext`, `pdftoppm`);
* для сканов (опционально): `tesseract` с языковыми пакетами `rus+eng`;
* для DjVu (опционально): утилиты `djvulibre` (`djvutxt`, `ddjvu`) — без них
  текст/OCR DjVu недоступны (аннотации ANTa читаются и без них).

```bash
# Debian/Ubuntu
sudo apt install poppler-utils tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng djvulibre-bin

# Fedora
sudo dnf install poppler-utils tesseract tesseract-langpack-ru tesseract-langpack-en djvulibre

# macOS
brew install poppler tesseract djvulibre

# Windows (winget) — либо добавьте папки bin в PATH вручную
winget install poppler tesseract-ocr oschwartz10612.DjVuLibre
```

Поиск утилит кроссплатформенный (Linux / macOS / Windows): каталог из
`TITLEMARK_TOOLS` → `PATH` (учитываются `.exe`/`.bat`) → типичные места
установки (Program Files\DjVuLibre, Homebrew, MacPorts, ~/.local/bin).
Утилиты, распакованные вручную рядом со своими библиотеками, запускаются
с автоматически подставленным путём к библиотекам. Если утилиты лежат в
необычном месте — задайте `TITLEMARK_TOOLS=C:\tools\bin`.

## Установка и запуск

```bash
# 1. прямо из исходников, без установки
cd titlemark
python3 -m titlemark --help

# 2. пользовательская установка — команда titlemark работает отовсюду
pip install --user .
titlemark --help

# 3. развёрнутая установка для разработки (правки исходников подхватываются сразу)
pip install --user -e .
```

После `pip install --user` команда попадает в `~/.local/bin`
(убедитесь, что этот каталог есть в `PATH`). Если вы правите исходники
проекта, запускайте из папки проекта либо переустановите пакет —
развёрнутая установка (`-e`) подхватывает изменения без переустановки.

## Использование

```bash
titlemark книга.pdf                  # показать план (файл НЕ меняется)
titlemark --apply книга.pdf          # переименовать файл
titlemark -r ~/Загрузки              # план по всей папке рекурсивно
titlemark --apply -r ~/Загрузки      # переименовать всё в папке
titlemark --report plan.csv -r .     # сохранить план в CSV
titlemark --force-ocr книга.pdf      # перепроверить PDF с кривым текстовым слоем
titlemark --ai книга.pdf             # пусть ИИ прочитает обложку
titlemark --title-from-text книга.pdf # название = весь текст страницы целиком
titlemark -n "{title}-{year}" книга.pdf # свой шаблон имени
titlemark -v книга.pdf               # отладка: кандидаты в заголовки, фрагмент текста
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `paths` | файл или папка (можно несколько) |
| `-a, --apply` | выполнить переименование; **без флага — только показать план (dry-run)** |
| `-r, --recursive` | обходить папки рекурсивно |
| `-n, --naming-template PATTERN` | шаблон имени с плейсхолдерами `{author}`, `{title}`, `{year}`; расширение дописывается само (по умолчанию: `{author} - {title} [{year}]`) |
| `--no-ocr` | не распознавать сканы (быстрее) |
| `--force-ocr` | всегда распознавать первые страницы через OCR и использовать этот текст вместо штатного текстового слоя (для PDF с кривой кодировкой) |
| `--ocr-pages N` | сколько первых страниц распознавать (по умолчанию 2) |
| `--no-year` | не добавлять год в имя файла |
| `--title-from-text` | собрать название из ВСЕГО текста страницы без спецсимволов («кусочки» названия складываются в целое), а не из отдельных строк-кандидатов |
| `--title-pages N` | сколько первых страниц брать для `--title-from-text` (по умолчанию 1) |
| `--report CSV` | записать отчёт: старое имя, новое имя, источник, статус |
| `-v, --verbose` | показывать кандидатов в заголовки и предупреждения |
| `-q, --quiet` | только итоговая статистика |

### Параметры ИИ (vision-LLM, только по явному флагу)

| Параметр | Описание |
|----------|----------|
| `--ai` | спросить ИИ по обложке документа; его ответ главнее эвристик |
| `--ai-url URL` | OpenAI-совместимый эндпоинт (по умолчанию `https://api.openai.com/v1`; Ollama: `http://localhost:11434/v1`) |
| `--ai-model MODEL` | модель (по умолчанию `gpt-4o-mini`; Ollama: `moondream`, `llava`, `llama3.2-vision`) |
| `--ai-key KEY` | ключ API (или env `TITLEMARK_AI_KEY`; локальному Ollama не нужен) |
| `--ai-timeout SEC` | таймаут запроса (по умолчанию 60) |

Переменные окружения: `TITLEMARK_AI_URL`, `TITLEMARK_AI_MODEL`, `TITLEMARK_AI_KEY`.

ИИ используется **только при флаге `--ai`**. Titlemark рендерит первую страницу
в PNG, показывает её модели вместе с кандидатами эвристик и получает строгий
JSON `{"title", "author", "year"}`. Если модель недоступна или ответила
странно — остаётся результат эвристик и печатается предупреждение.

```bash
# облако (OpenAI, DeepSeek, GigaChat, YandexGPT и любой совместимый API)
export TITLEMARK_AI_KEY=sk-...
titlemark --ai книга.pdf

# локальный Ollama, полностью офлайн
titlemark --ai --ai-url http://localhost:11434/v1 --ai-model moondream книга.pdf
```

## Как выбирается имя

По умолчанию имя строится по шаблону **«Автор - Название [год].расширение»**
(если автор не найден — просто «Название [год].расширение»). Шаблон
настраивается: `--naming-template "{author} - {title}"`, `"{title}-{year}"`,
`"{year}_{title}"` — пустые значения убираются вместе со своими разделителями,
расширение файла дописывается автоматически.

Источники данных проверяются по убыванию надёжности:

1. **Метаданные файла** — Title/Author/date; мусорные значения вида
   `Microsoft Word - …`, `Layout 1`, `Pamyat_text 02.indd`, хэши и номера
   отбрасываются;
2. **Текстовый слой первых страниц** — строки оцениваются по регистру
   (ЗАГЛАВНЫЕ/Title Case), положению на странице, длине, пунктуации;
   отбрасываются служебки (ISBN, УДК, колонтитулы, ссылки), издательские
   строки («Москва · Санкт-Петербург», «Города O'Reilly»), заголовки разделов
   («Table of Contents», «Предисловие») и строки-имена; подзаголовок со
   следующих строк склеивается с названием;
3. **OCR первых страниц** — если текстового слоя нет (скан) или он испорчен:
   кракозябры от нестандартной кодировки, раздробленные слова
   («W ICKED COOL», «SHELL SCRIP T S»);
4. **Имя исходного файла** — используется, когда другие источники дали обрывок
   («ВЕСЬ» из «Весь Linux…»), шифр («М. МЦНМО, 2016»), кривую библиографическую
   запись или ошибочный OCR; из имени разбираются форматы «Автор - Название»,
   «Название (Автор)», «03_Название_by_Автор».

Разделение «имя автора» / «короткий заголовок» (оба могут быть набраны
ЗАГЛАВНЫМИ: `АРТУР ДУМЧЕВ` против `DARK MATTER`) делается по компактному
словарю распространённых русских, английских имён и их транслитераций
(`titlemark/names.py`) — словарь легко дополнять.

Строки с именами в формате «Фамилия И. О.», «И. О. Фамилия»,
«Фамилия, Имя», «by Jane Smith» распознаются шаблонами. Имя в капсе
нормализуется (`АРТУР ДУМЧЕВ` → `Артур Думчев`), служебные слова
(«And Unix Systems») не считаются именем.

## Безопасность

* **по умолчанию ничего не переименовывает** — только показывает план;
* коллизии имён разрешаются суффиксом ` (2)`, ` (3)`;
* расширение файла сохраняется, запрещённые символы заменяются пробелами;
* длина имени ограничена 200 **байт** (лимит ФС — 255 байт на компонент,
  кириллица занимает 2 байта), обрезка по границе слова с `…`;
* год попадает в имя только если найден в метаданных или исходном имени.

## Тесты

```bash
python3 -m unittest discover -s tests
```

128 тестов: эвристики заголовков/авторов, очистка текста, детект кракозябр,
построение имён, разбор имён файлов, синтетические файлы всех поддерживаемых
форматов, сценарии переименования.

## Структура проекта

```
titlemark/
├── titlemark/
│   ├── cli.py               # аргументы командной строки, вывод плана
│   ├── renamer.py           # планирование и выполнение переименования
│   ├── titlefinder.py       # эвристики: заголовок и автор из текста
│   ├── names.py             # словарь имён: «имя автора» или «заголовок»
│   ├── textclean.py         # очистка строк, детект кракозябр
│   ├── naming.py            # сборка имени файла, лимиты, коллизии
│   ├── ocr.py               # OCR первых страниц (pdftoppm + tesseract)
│   ├── signature.py         # определение формата по сигнатуре (файлы без расширения)
│   ├── ai.py                # распознавание обложки ИИ (--ai, OpenAI-совместимый API)
│   ├── models.py            # DocumentInfo, Source, TextQuality
│   └── extractors/          # PDF, EPUB, FB2, MOBI, DJVU, DOCX
├── tests/
├── pyproject.toml
├── README.md                # английская документация
└── README.ru.md             # этот файл
```
